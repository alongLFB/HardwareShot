硬件配置助手
==================

双击「硬件配置助手.exe」即可使用,无需安装,无需联网,不需要管理员权限。

【基本流程】
1. 打开后自动扫描硬件(约 4 秒),右侧实时预览配置长图。
2. 点「保存配置长图」(F2),图片会保存到下方「保存目录」,并自动复制到剪贴板,
   直接去微信/QQ 里 Ctrl+V 就能发给好友。
3. 想改保存位置:左下角「更改目录」。

【和好友对比硬件】
1. 你和好友都运行本工具,各自点「导出配置文件 (.json)」。
2. 好友把 .json 发给你。
3. 你点「导入好友配置 → 对比」,选择好友的 .json,
   会生成「关键指标条形图 + 逐项差异对比」的长图,同样可以 F2 保存 / F3 复制。
   (在左侧填好「昵称」,图上会显示你们的名字。)

【辅助截图】
- 区域截图(F4):窗口隐藏后拖动鼠标框选任意区域,松开即保存并复制;Esc / 右键取消。
  可用来截取任何窗口(例如 GPU-Z、任务管理器),方便一起发给好友。
- 其它快捷键:F5 重新扫描,F3 复制当前长图。

【隐私说明】
只读取型号、容量、频率等公开规格;不会读取/上传序列号、MAC、IP、用户名、电脑名。
全程离线,数据只保存在你选择的目录里。

【常见问题】
- 杀毒软件误报:程序由 Python + PyInstaller 打包,个别杀软可能误报,选择「信任/允许」即可。
- 显示器名称显示为 Generic PnP Monitor / 型号不全:取决于显示器 EDID 信息,属正常现象。
- 设置保存在 %APPDATA%\HardwareShot\settings.json。
- 系统要求:Windows 10 / 11(自带 PowerShell 5.1)。
