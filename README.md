# 硬件配置助手 (HardwareShot)

一款轻量、免安装、纯离线的 Windows 电脑硬件配置检测、长图生成与双机对比工具。
支持一键扫描电脑核心硬件、生成高清配置长图并自动复制到剪贴板、辅助区域截图，以及通过导入 `.json` 配置文件与好友电脑进行直观的硬件对比。

---

## 功能特性

- **全面硬件检测**：自动识别整机品牌型号、操作系统版本与运行时间、处理器（核心/线程/频率/三缓）、内存（品牌/代数/频率/单条容量/插槽占用）、显卡（显存容量/非公版品牌如华硕/技嘉/微星/驱动版本）、主板与 BIOS、显示器（品牌/物理英寸/分辨率/刷新率）、硬盘（品牌/固态或机械/总线类型/系统盘标识）、物理网卡及声卡。
- **高清长图生成与一键分享**：
  - 内置 **8 套精心调色的高颜值主题**（**科技蓝**、**赛博朋克**、**ROG电竞**、**极客绿**、**黑金奢华**、**冰川极光**、**深色**、**浅色**）。
  - 支持自定义顶部显示的昵称（如：`阿龙 的电脑配置`）。
  - 支持切换是否展示细项参数（频率、驱动、BIOS 等）。
  - 保存长图（`F2`）时可自动写入系统剪贴板，直接在微信、QQ、钉钉中 `Ctrl + V` 即可发送。
- **好友硬件对比**：
  - 支持将本机配置导出为轻量的 `.json` 文件发给好友。
  - 导入好友的 `.json` 配置文件后，自动生成包含 **关键指标横向条形图**（CPU 核心/线程、内存容量/频率、显存容量、硬盘总容量）与 **逐项配置差异高亮** 的对比长图。
- **快速辅助区域截图 (`F4`)**：
  - 一键隐藏主窗口并框选任意屏幕区域（如 GPU-Z、任务管理器、游戏帧率画面），松开鼠标即自动保存到指定目录并复制到剪贴板。
- **隐私安全**：
  - 全程离线运行，仅读取硬件公开规格参数，**绝不读取或上传** 序列号（SN）、MAC 地址、IP 地址、电脑名或系统用户名。

## 快速使用指南

### 1. 直接运行（免安装版）
1. 解压 `dist/硬件配置助手.zip` 或直接双击运行 `dist/硬件配置助手/硬件配置助手.exe`。
2. 打开后程序自动扫描本机硬件（约 3~5 秒），右侧画布实时预览配置长图。
3. 点击左侧 **「保存配置长图 F2」**，长图会保存到设定的目录并自动复制到剪贴板，直接去聊天窗口粘贴即可。

### 2. 与好友电脑进行对比
1. 你和好友各自打开本工具，点击左侧 **「导出配置文件 (.json)」**。
2. 让好友把生成的 `.json` 文件发给你。
3. 在你的工具上点击 **「导入好友配置 → 对比」**，选择好友发来的 `.json` 文件。
4. 右侧会自动切换为双机对比长图，按 `F2` 保存或 `F3` 复制即可分享对比结果；点击 **「返回本机配置」** 可切回单机视图。

### 3. 快捷键一览

| 快捷键 | 功能说明 |
| :--- | :--- |
| `F2` | 保存当前配置长图 / 对比长图到指定目录（并按设置复制到剪贴板） |
| `F3` | 仅将当前长图复制到系统剪贴板 |
| `F4` | 启动屏幕区域截图（拖动鼠标框选，`Esc` 或鼠标右键取消） |
| `F5` | 重新扫描本机硬件信息 |

## 开发者指南（源码运行与打包）

### 环境要求
- **操作系统**：Windows 10 / Windows 11（需系统自带 PowerShell 5.1+）
- **Python 版本**：Python 3.9 及以上（推荐 Python 3.11，需包含标准库 `tkinter`）

### 1. 安装依赖

```powershell
pip install -r requirements.txt
```

### 2. 从源码直接运行

```powershell
python main.py
```

### 3. 运行自测脚本
生成三套主题的本机长图及模拟好友对比图到 `out/` 目录：

```powershell
python selftest.py
```

### 4. 一键打包为单文件 EXE 与发布压缩包

```powershell
python build.py
```

打包完成后，产物位于 `dist/` 目录：
- `dist/硬件配置助手/硬件配置助手.exe`：独立单文件可执行程序
- `dist/硬件配置助手/使用说明.txt`：面向普通用户的简明说明
- `dist/硬件配置助手.zip`：可直接发给好友的完整压缩包

## 项目结构

```text
HardwareShot/
├── main.py          # 程序启动入口
├── app.py           # Tkinter 主界面与全屏区域截图交互 (RegionSelector)
├── collector.py     # 基于 PowerShell (CIM/WMI) 与 Win32 API 的硬件采集与中文化清洗
├── renderer.py      # 基于 Pillow 的高清长图与双机对比图排版渲染引擎
├── winutil.py       # Windows DPI 感知、CF_DIB 剪贴板写入、资源管理器定位与配置持久化
├── build.py         # 自动绘制应用图标并调用 PyInstaller 打包生成 exe 与 zip
├── selftest.py      # 命令行渲染自测脚本
├── README.txt       # 随 zip 发布包附带的纯文本使用说明
├── README.md        # 项目完整文档与开发手册
├── requirements.txt # Python 依赖清单
└── .gitignore       # Git 忽略规则配置
```

## 常见问题

- **杀毒软件提示或拦截？**
  本工具使用 Python + PyInstaller 打包为单文件 `.exe`，且未购买商业数字签名，个别杀毒软件可能会对 PyInstaller 引导程序产生误报，选择「信任 / 允许运行」即可，或直接通过 `python main.py` 运行源码。
- **用户设置保存在哪里？**
  昵称、主题、默认保存目录等个性化配置保存在 `%APPDATA%\HardwareShot\settings.json`，删除该文件即可恢复默认设置。
- **默认图片保存在哪里？**
  默认保存在当前用户的 `图片\硬件配置`（`~\Pictures\硬件配置`）目录下，可在软件左下角随时点击「更改目录」修改。
